# Making SD card apps

Apps are small programs the dashboard loads from the SD card, so you don't have to rebuild
and reflash the firmware for each one. They show up in the **Custom Apps** folder on the home
screen. `analog_clock/` is a complete example.

An app is a compiled ELF file wrapped in a small signed header (a `.app` file). The display
loads it into PSRAM with Espressif's [elf_loader](https://components.espressif.com/components/espressif/elf_loader)
when you open it, and unloads it when you leave.

## Security first

An app is native code with **full access to the display**: saved Wi-Fi passwords, the Jellyfin
key, everything. The ESP32 can't fence it off. So the display only runs apps that are:

- **signed by a trusted key**: the built-in keys (every `.pub` file in `keys/`, compiled into the
  firmware) or keys you've accepted on screen, or
- **unsigned, in developer mode**, after you approve that exact file on screen (it asks again
  if the file changes).

The private signing key is `local-keys/app_signing_key.pem`. It's in `.gitignore`, readable only
by you, and must never be committed or shared. Anyone with it can make apps your display trusts.

## Make an app

1. Copy `analog_clock/` to a new folder, e.g. `apps/my_app/`, and rename things:
   - `CMakeLists.txt`: `project(my_app)` and `project_elf(my_app)`.
   - `main/CMakeLists.txt`: your source file names.
   - `app.json`: the tile's name, version, symbol and colour:
     ```json
     { "name": "My App", "version": "1.0", "symbol": "star", "color": "0x1E88E5" }
     ```
     `symbol` is one of LVGL's built-in icons; `tools/appkey.py` lists the names if you pick one
     that doesn't exist.
2. Write the app. `app_main()` runs when the app is opened and registers two callbacks:
   ```c
   #include "dashboard_app.h"

   static void create(lv_obj_t *parent)  /* build the UI in the 800 x 416 area */
   {
       lv_obj_t *l = lv_label_create(parent);
       lv_label_set_text(l, "Hello!");
       lv_obj_center(l);
   }

   static void destroy(void)             /* delete your lv_timers, free memory */
   {
   }

   int app_main(int argc, char *argv[])
   {
       static const dash_app_def_t def = {
           .api_version = DASH_API_VERSION, .create = create, .destroy = destroy,
       };
       dash_app_register(&def);
       return 0;
   }
   ```
3. Build and sign it (from the project folder):
   ```bash
   tools/build_app.sh apps/my_app                # -> build/apps/my_app.app, signed
   ```
4. Copy it to the display over USB and restart it:
   ```bash
   PY=~/.espressif/python_env/idf5.5_py3.14_env/bin/python
   $PY tools/sdcard.py put build/apps/my_app.app apps/
   ```
   (Or copy the file into `dashboard/apps` on the card.) A new app appears after a restart; an
   updated version of an app that's already there runs the next time you open it.

## What apps can use

- **LVGL 8.4** (the firmware's copy, with its fonts: Montserrat 14, 20, 28 and 48).
- **C library basics**: strings, `snprintf`, `malloc`/`free`, `time`/`localtime_r`/`strftime`,
  maths (`sinf`, `cosf`, `sqrtf`, ...).
- **The dashboard API** in `sdk/dashboard_sdk/include/dashboard_app.h`: `dash_toast()`,
  `dash_time_is_set()`, `dash_clock_24h()`, `dash_alloc()` / `dash_free()` (PSRAM),
  `dash_now_ms()`.

If an app calls something the firmware doesn't offer, the display says which function was
missing when you open it. The list of what's offered is generated by `tools/gen_app_symbols.py`
(`main/app_symbols.c`).

Rules: everything runs in the LVGL task (LVGL calls are fine in `create()`, events and
`lv_timer`s). Leave nothing running after `destroy()`: no timers or tasks, because the app's
code is unloaded about a second later.

## Unsigned apps and other people's keys

- `tools/build_app.sh apps/my_app --unsigned` makes an unsigned app. It runs only with
  **Settings > Apps > Developer mode** on, and asks before running (DEV shows on the home screen
  while developer mode is on).
- To run someone else's signed apps, put their public key (`something.pub`) in
  `dashboard/import` and restart. A full-screen warning shows the key's fingerprint: check it
  with them, hold **Trust** for 3 seconds, then give the key a name (the file name is only a
  suggestion). Keys are listed (and removed) in Settings > Apps.
- To make another key always trusted by your firmware, copy its `.pub` file into `keys/` and
  rebuild (up to 4 built-in keys).
- To make a key pair for someone else: `tools/appkey.py genkey --out ~/their-keys`. The display
  names a key after its file, so rename `app_signing_key.pub` to e.g. `bobs_apps.pub` before
  sharing it.
- `tools/appkey.py info build/apps/my_app.app` shows an app's details and checks its signature.
